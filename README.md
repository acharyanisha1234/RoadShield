# 🛡️ RoadShield

Smart road safety & accident detection platform.

## Stack
- **Mobile:** React Native (Expo) + NativeWind (TailwindCSS)
- **Backend:** Node.js + Express.js
- **AI:** Python + FastAPI
- **Database:** MongoDB
- **Real-time:** Socket.IO

## Structure
- `mobile/` — React Native app
- `backend/` — Node.js API
- `ai-service/` — Python AI
- `admin-web/` — React admin panel
