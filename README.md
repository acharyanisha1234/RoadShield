### RoadShield – Real-Time Road Safety & Incident Reporting System

RoadShield is a **real-time road safety and incident reporting application** designed to help users report road hazards and safety incidents using their mobile devices.

The system allows users to **report incidents with their location, photos, severity, and incident type**, while the location is displayed on an interactive map. It also provides **real-time updates using Socket.IO**, allowing users and authorized authorities to receive updated incident information without manually refreshing the application.

The system includes separate roles for **Users, Admins, and Police**, with role-based access and authentication. Users can submit and track reports, while authorized personnel can manage reports, monitor road-safety hotspots, and view statistics. The application also includes an **SOS feature** for emergency situations and location tracking to improve response and awareness.

### Main Technologies Used

* **Frontend:** React Native, Expo, React Native Maps
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Authentication:** JWT, bcrypt
* **Real-Time Communication:** Socket.IO
* **Location & Maps:** Expo Location, React Native Maps
* **AI Support Service:** Python, FastAPI, OpenCV, NumPy, scikit-learn
* **Styling:** NativeWind/Tailwind CSS

### Main Objective

The main objective of RoadShield is to provide a centralized platform where road-related incidents can be **reported, located, monitored, and managed in real time**, helping improve communication between road users and responsible authorities.

### Key Features

* User registration and secure login
* Road incident reporting
* Photo/camera-based evidence
* GPS-based location tracking
* Interactive map with incident markers
* Incident type and severity classification
* Real-time incident updates
* SOS/emergency functionality
* User, Admin, and Police roles
* Road-safety hotspot monitoring
* Incident statistics and reports
* Backend API and database management
* AI-service integration for supporting incident analysis
